## Описание проекта

Разработка интернет-магазина органических продуктов с каталогом, корзиной и онлайн-оплатой.

## Стек

- HTML5 / CSS3 / JavaScript
- WooCommerce + WordPress
- Stripe для оплаты

## Что сделано

- Полностью адаптивный дизайн (mobile-first)
- Каталог с фильтрами по категориям
- Корзина с сохранением состояния в localStorage
- Интеграция платёжной системы
- SEO-оптимизация страниц товаров

## Результат

- Конверсия в покупку выросла на **22%** за первый месяц
- Время загрузки главной страницы — **0.8 сек**
- Показатель Lighthouse Performance — **97/100**
