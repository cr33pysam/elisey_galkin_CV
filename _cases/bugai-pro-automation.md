## Контекст

**BUGAI.PRO** — креативное агентство конвейерного производства контента. Команда из 10 специалистов работала без единой системы: каждый держал задачи в голове, уточнения приходили по нескольку раз на день, а подготовка к онлайн-съёмкам занимала полдня рутиной.

Моя задача как Project Administrator была выстроить архитектуру процессов так, чтобы команда работала предсказуемо, а руководители видели статус проектов без ежедневных синхронных встреч.

## Задачи

- Убрать хаос в задачах и коммуникации
- Сократить время на рутинные операции (таймшиты, проверки, согласования)
- Стандартизировать подготовку к съёмкам
- Внедрить AI-инструменты в производство контента
- Обеспечить прозрачность B2B-проектов

## Процесс

**База знаний в BuildIn.** Я спроектировал и внедрил внутреннюю архитектуру базы знаний: структура отделена по ролям, добавлены шаблоны ответов и searchable-рубрикация. Результат — снижение уточняющих обращений на **67%**, команда стала работать автономнее.

**Telegram-бот на Python.** Инициировал разработку бота с ИИ-интеграцией для автоматизации заполнения таймшитов. Команда больше не тратила время на ручное заполнение — бот сам собирал данные из задач и формировал отчёты. Экономия времени — **46%**.

**Реорганизация Asana.** Перестроил воркфлоу для команды из 10 человек: ввёл шаблоны задач, единую структуру колонок, автоматические триггеры на дедлайны. Еженедельные синк-митинги сократились в **1,5 раза**, дедлайны вышли из зоны риска.

**Чек-листы для съёмок.** Разработал 3 стандартизированных чек-листа для 24+ ежегодных онлайн-съёмок: от технической готовности до выхода в эфир. Время подготовки снизилось с 5 часов до 1,5 часов на эфир, риски сбоев для ведущего и команды свелись к минимуму.

**AI-пакет для производства.** Внедрил в работу 3 человек пакет ИИ-инструментов для генерации текстов, изображений, видео и аватаров. Подготовка черновых вариантов контента ускорилась в **2 раза**, производственный цикл оптимизирован.

**Метрики из соцсетей.** Автоматизировал сбор и структурирование метрик из 4 социальных сетей для 6 ежемесячных проектов — копирайтеры получили данные для принятия решений, релевантность контента выросла.

| Метрика | Было | Стало | Изменение |

| Время синк-митингов | 2 ч/нед | 1,3 ч/нед | **−35%** |

## Что получилось

- **BuildIn Knowledge Base** — архитектура внутренней базы знаний, снижения уточнений на 67%
- **Telegram AI-бот** — автоматизация таймшитов на Python, экономия 46% времени команды
- **Asana Workflow** — реорганизованная система задач для 10 человек с шаблонами и триггерами
- **3 чек-листа съёмок** — стандарт для 24+ онлайн-трансляций в год
- **AI-пакет производства** — тексты, изображения, видео, аватары для 3 специалистов
- **Автоматизация метрик** — сбор данных из 4 соцсетей для 6 проектов ежемесячно
