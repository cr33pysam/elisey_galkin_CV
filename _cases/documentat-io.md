## Контекст

**documentat.io** — платформа обучения и аутстаффа технических писателей. На момент моего прихода в марте 2026 команда росла, но процессы были неструктурированы: клиентские запросы обрабатывались медленно, сроки сорвались, а подготовка регламентов занимала часы ручной работы.

За 8 месяцев я управлял кросс-функциональной командой на всех этапах SDLC по разработке backend-архитектуры и параллельно — циклом 15 edtech-продуктов, из которых 5 были запущены с нуля при бюджете 500+ тыс. руб.

## Задачи

- Синхронизировать бэк-офис, PR и методистов для синхронного выпуска курсов
- Автоматизировать рутинные процессы подготовки регламентов и администрирования
- Выстроить систему согласования задач для 11 экспертов без перегрузки
- Обеспечить прозрачность процессов для всех стейкхолдеров
- Найти каналы масштабирования edtech-продуктов

## Процесс

**Автоматизация ИИ-инструментами.** Я внедрил набор AI-ассистентов для подготовки регламентов — это покрыло 50% команды. Время на рутину сократилось с 1,5 часов до 20 минут. Параллельно запустил AI-ассистентов для фасилитации встреч с ключевыми стейкхолдерами — договорённости перестали теряться, контроль статусов перевёл в системный формат.

**Roadmap и декомпозиция.** Сформировал стратегический roadmap и декомпозировал тактические задачи для 18 потоков курсов. Это обеспечило строгий контроль сроков и своевременный релиз продуктов без «пожарных» режимов.

**Координация экспертов.** Выстроил систему согласования для 11 экспертов: равномерная загрузка, минимизация проектных рисков, прозрачные дедлайны.

**Анализ продукта.** Провёл анализ метрик и пути студента — выявил спад интереса джунов на 50%. Это стало основой для решения по расширению линейки курсов и выходу в ВУЗы.

**Рынок и дистрибуция.** Провёл аудит рынка и сформировал шорт-лист из 10+ каналов дистрибуции. Представлял продукты на конференции TeamLead Syberia 2026 (500+ участников), вел переговоры с ЛПР.

## Что получилось

- **Стратегический roadmap** на 18 потоков курсов с декомпозицией до тактических задач
- **AI-регламенты**: автоматизация для 50% команды, время сокращено в 4,5 раза
- **Система согласования** для 11 экспертов — равномерная загрузка, минимум рисков
- **Продуктовая аналитика**: выявлен спад интереса джунов на 50%, основа для расширения
- **Шорт-лист из 10+ каналов дистрибуции** для масштабирования охвата
- **Конференционное представление**: TeamLead Syberia 2026, переговоры с ЛПР
